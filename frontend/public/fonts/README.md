# Self-hosted IBM Plex fonts

These Latin WOFF2 subsets were obtained from Fontsource packages
`@fontsource/ibm-plex-mono@5.2.7` and `@fontsource/ibm-plex-sans@5.2.7`.
They are served from the same GitHub Pages origin so the application and 5250
iframe make no third-party font requests. The SIL Open Font License 1.1 is
preserved in `LICENSE.txt`.
